---
title: closestTo
description: Find the date, time, or datetime nearest to a target
---

Returns the candidate nearest to `target`, before or after it, exactly as it was given.

## Signature

```ts
function closestTo<T extends Temporal.Instant | Temporal.ZonedDateTime>(
  target: Temporal.Instant | Temporal.ZonedDateTime,
  candidates: readonly T[]
): T | undefined;
function closestTo(
  target: Temporal.PlainDate,
  candidates: readonly Temporal.PlainDate[]
): Temporal.PlainDate | undefined;
function closestTo(
  target: Temporal.PlainTime,
  candidates: readonly Temporal.PlainTime[]
): Temporal.PlainTime | undefined
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `target` | `PlainDate`, `PlainTime`, or `Instant \| ZonedDateTime` | The value to measure from |
| `candidates` | Array of the same kind | Values to choose from; may be empty |

## Returns

The nearest candidate, or `undefined` when `candidates` is empty.

## Examples

### Find the nearest train departure

```ts
import { closestTo } from '@gobrand/tiempo';

const now = Temporal.Instant.from('2026-01-20T12:00:00Z');
const departures = [
  Temporal.Instant.from('2026-01-20T09:00:00Z'),
  Temporal.Instant.from('2026-01-20T13:30:00Z'),
  Temporal.Instant.from('2026-01-20T18:00:00Z'),
];

closestTo(now, departures); // 2026-01-20T13:30:00Z
closestTo(now, []); // undefined
```

### Find the next departure only

```ts
import { closestTo, isAfter } from '@gobrand/tiempo';

const now = Temporal.Instant.from('2026-01-20T12:00:00Z');
const departures = [
  Temporal.Instant.from('2026-01-20T11:55:00Z'),
  Temporal.Instant.from('2026-01-20T13:30:00Z'),
];

closestTo(now, departures.filter((d) => isAfter(d, now))); // 2026-01-20T13:30:00Z
```

## Good to know

- PlainTimes are measured within one day, without wrapping at midnight: 23:30 is far from 00:15.
- Ties return the first candidate.
- Mixing a PlainDate or PlainTime with another kind throws a `TypeError`.
