---
title: addMicroseconds
description: Add a number of microseconds to a datetime.
---

Adds exact microseconds of elapsed time, for trace spans and database timestamps stored in microseconds.

## Signature

```ts
function addMicroseconds(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  microseconds: number
): Temporal.ZonedDateTime;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.Instant \| Temporal.ZonedDateTime` | The starting datetime |
| `microseconds` | `number` | Whole number of microseconds to add; negative goes back. Fractions throw a `RangeError`. |

## Returns

A `ZonedDateTime` in the input's timezone, or in UTC for an `Instant`.

## Examples

### Find when a 340 µs trace span ended

```ts
import { addMicroseconds } from '@gobrand/tiempo';

const spanStart = Temporal.Instant.from('2026-04-01T10:00:00.000125Z');

addMicroseconds(spanStart, 340); // 2026-04-01T10:00:00.000465+00:00[UTC]
```
