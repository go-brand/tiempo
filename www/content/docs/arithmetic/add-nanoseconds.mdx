---
title: addNanoseconds
description: Add a number of nanoseconds to a datetime.
---

Adds exact nanoseconds of elapsed time, the smallest unit Temporal stores. Use it for durations from `process.hrtime.bigint()` or OpenTelemetry.

## Signature

```ts
function addNanoseconds(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  nanoseconds: number
): Temporal.ZonedDateTime;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.Instant \| Temporal.ZonedDateTime` | The starting datetime |
| `nanoseconds` | `number` | Whole number of nanoseconds to add; negative goes back. Fractions throw a `RangeError`. |

## Returns

A `ZonedDateTime` in the input's timezone, or in UTC for an `Instant`.

## Examples

### Find when an operation finished from its measured duration

```ts
import { addNanoseconds } from '@gobrand/tiempo';

const startedAt = Temporal.Instant.from('2026-04-01T10:00:00.250Z');

addNanoseconds(startedAt, 1_250_000); // 2026-04-01T10:00:00.25125+00:00[UTC]
```

## Good to know

- `nanoseconds` is a `number`, not a `bigint`. Convert with `Number(duration)`; values above `Number.MAX_SAFE_INTEGER` (about 104 days) lose precision.
