---
title: subWeeks
description: Subtract weeks from a datetime or calendar date
---

Subtracts the specified number of weeks from a datetime or calendar date.

PlainDate inputs return a PlainDate and preserve its calendar, without choosing a timezone. Instant inputs continue to return a ZonedDateTime in UTC; ZonedDateTime inputs preserve their timezone. Counts may be negative; fractional calendar counts are rejected by Temporal. Month/year arithmetic uses Temporal’s default month-end constraining.

## Signature

```ts
function subWeeks(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  weeks: number
): Temporal.ZonedDateTime;
function subWeeks(input: Temporal.PlainDate, weeks: number): Temporal.PlainDate;
```

## Example

```ts
import { subWeeks } from '@gobrand/tiempo';

const now = Temporal.Now.zonedDateTimeISO();

// Get last week
const lastWeek = subWeeks(now, 1);

// Get 4 weeks ago
const fourWeeksAgo = subWeeks(now, 4);
```

## Date-only arithmetic

```ts
import { subWeeks, toPlainDate } from '@gobrand/tiempo';

const date = toPlainDate('2024-01-31');
const result = subWeeks(date, 1); // Temporal.PlainDate
result.toString(); // "2024-01-24"
```
