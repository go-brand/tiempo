---
title: addMonths
description: Add a number of months to a date or datetime.
---

Adds calendar months and keeps the day of the month and the wall-clock time. A day that does not exist in the target month moves back to that month's last day: January 31 plus one month is February 28.

## Signature

```ts
function addMonths(input: Temporal.PlainDate, months: number): Temporal.PlainDate;
function addMonths(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  months: number
): Temporal.ZonedDateTime;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.PlainDate \| Temporal.Instant \| Temporal.ZonedDateTime` | The starting date or datetime |
| `months` | `number` | Whole number of months to add; negative goes back. Fractions throw a `RangeError`. |

## Returns

A `PlainDate` for a `PlainDate` input. Otherwise a `ZonedDateTime` in the input's timezone, or in UTC for an `Instant`.

## Examples

### Renew a subscription started on January 31

```ts
import { addMonths } from '@gobrand/tiempo';

const started = Temporal.PlainDate.from('2026-01-31');

addMonths(started, 1); // 2026-02-28
addMonths(started, 2); // 2026-03-31
addMonths(started, 3); // 2026-04-30
```

### Run a monthly billing job at 09:00 Madrid time

Spain moves to summer time on March 29; the job stays at 09:00.

```ts
import { addMonths } from '@gobrand/tiempo';

const billingRun = Temporal.ZonedDateTime.from('2026-03-15T09:00:00+01:00[Europe/Madrid]');

addMonths(billingRun, 1); // 2026-04-15T09:00:00+02:00[Europe/Madrid]
```

## Good to know

- Count each renewal from the original date. Chaining loses the 31st: one month after February 28 is March 28.
