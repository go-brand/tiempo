---
title: today
description: Get today's date in a timezone, as a PlainDate.
---

Returns today's date in the timezone you name. At 23:30 UTC it is already tomorrow in Tokyo, so the timezone matters.

## Signature

```ts
function today(timezone: Timezone): Temporal.PlainDate
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `timezone` | `Timezone` | An IANA timezone name, such as `'Asia/Tokyo'`, or `'UTC'`. |

## Returns

A `Temporal.PlainDate`.

## Examples

### Count the days until an invoice is due

```ts
import { today, toPlainDate, differenceInDays } from '@gobrand/tiempo';

const due = toPlainDate('2026-12-31');
const daysLeft = differenceInDays(due, today('America/New_York')); // 53 on 2026-11-08
```

### Set a trial end date 14 days out

```ts
import { today, addDays, differenceInDays } from '@gobrand/tiempo';

const start = today('Europe/Madrid');
const trialEnds = addDays(start, 14);

differenceInDays(trialEnds, start); // 14
```
