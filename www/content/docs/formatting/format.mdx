---
title: format
description: Format a date or time as text using date-fns-style tokens.
---

Formats a date or time as text with date-fns-style tokens, such as `"MMMM d, yyyy"`.

## Signature

```ts
function format(
  input: Temporal.PlainDate,
  formatStr: string,
  options?: { locale?: string }
): string

function format(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  formatStr: string,
  options?: { locale?: string; timeZone?: Timezone }
): string
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.Instant \| Temporal.ZonedDateTime \| Temporal.PlainDate` | The value to format. |
| `formatStr` | `string` | The pattern. See [Tokens](#tokens). Text in single quotes is printed as is. |
| `options.locale` | `string` | Locale for month, weekday, and timezone names. Default `'en-US'`. |
| `options.timeZone` | `Timezone` | Timezone to show the moment in. Default: UTC for an `Instant`, its own timezone for a `ZonedDateTime`. |

## Returns

The formatted string.

## Examples

### Show an appointment to a customer

```ts
import { format } from '@gobrand/tiempo';

const appointment = Temporal.ZonedDateTime.from('2026-06-02T14:05:00[America/Los_Angeles]');

format(appointment, "EEEE, MMMM d 'at' h:mm a"); // "Tuesday, June 2 at 2:05 PM"
format(appointment, 'MMM d, h:mm a zzz'); // "Jun 2, 2:05 PM PDT"
```

### Show a UTC payment time in the customer's timezone

```ts
import { format } from '@gobrand/tiempo';

const paidAt = Temporal.Instant.from('2026-06-02T14:05:00Z');

format(paidAt, 'yyyy-MM-dd HH:mm z'); // "2026-06-02 14:05 UTC"
format(paidAt, 'yyyy-MM-dd HH:mm z', { timeZone: 'America/New_York' }); // "2026-06-02 10:05 EDT"
```

### Format a due date in Spanish

```ts
import { format, toPlainDate } from '@gobrand/tiempo';

const due = toPlainDate('2026-04-15');

format(due, "EEEE d 'de' MMMM", { locale: 'es-ES' }); // "miércoles 15 de abril"
```

## Tokens

Results for `2026-06-02T14:05:07.123-07:00[America/Los_Angeles]` in `en-US`. A `PlainDate` supports the era, year, quarter, month, day, and weekday tokens.

| Unit | Token | Result |
|------|-------|--------|
| Era | `G`, `GG`, `GGG` | AD |
| | `GGGG` | Anno Domini |
| | `GGGGG` | A |
| Year | `y` | 2026 |
| | `yy` | 26 |
| | `yyy`, `yyyy` | 2026 (padded to 3 or 4 digits) |
| Quarter | `Q`, `QQQQQ` | 2 |
| | `QQ` | 02 |
| | `QQQ` | Q2 |
| | `QQQQ` | 2nd quarter |
| Month | `M` | 6 |
| | `MM` | 06 |
| | `Mo` | 6th |
| | `MMM` | Jun |
| | `MMMM` | June |
| | `MMMMM` | J |
| Day of month | `d` | 2 |
| | `dd` | 02 |
| | `do` | 2nd |
| Day of week | `E`, `EE`, `EEE` | Tue |
| | `EEEE` | Tuesday |
| | `EEEEE` | T |
| | `EEEEEE` | Tu |
| AM/PM | `a`, `aa` | PM |
| | `aaa` | pm |
| | `aaaa` | p.m. |
| | `aaaaa` | p |
| Hour (0–23) | `H` | 14 |
| | `HH` | 14 (2 digits) |
| Hour (1–12) | `h` | 2 |
| | `hh` | 02 |
| Minute | `m` | 5 |
| | `mm` | 05 |
| Second | `s` | 7 |
| | `ss` | 07 |
| Fraction of second | `S` | 1 |
| | `SS` | 12 |
| | `SSS` | 123 |
| Offset (`Z` for UTC) | `X` | -07 |
| | `XX`, `XXXX` | -0700 |
| | `XXX`, `XXXXX` | -07:00 |
| Offset | `x` | -07 |
| | `xx`, `xxxx` | -0700 |
| | `xxx`, `xxxxx` | -07:00 |
| Timezone name | `z`, `zz`, `zzz` | PDT |
| | `zzzz` | Pacific Daylight Time |
| Timestamp | `T` | 1780434307123 (milliseconds) |
| | `t` | 1780434307 (seconds) |

## Good to know

- Quote every word that is not a token. Letters like `a` and `t` are tokens, so `'h:mm a at'` prints `"2:05 PM PM1780434307"`. Write `"h:mm a 'at'"` instead.
- Unsupported letters (such as `D`, `w`, `L`) are printed as is, and ordinals (`do`, `Mo`, `QQQQ`) are always English.
