## Two values or an interval?

Difference functions take **two values in subtraction order**: the first minus the second. Interval functions take **one range object** with named `start` and `end` endpoints. These calling shapes follow date-fns conventions.

| Task | Shape | Meaning |
|------|-------|---------|
| Calculate a difference | `differenceInDays(later, earlier)` | Signed day count; swapping arguments can make it negative |
| Compare two values | `isBefore(a, b)` | Whether `a` comes before `b` |
| Add an amount | `addDays(date, amount)` | A new value, leaving the input unchanged |
| List a range | `eachDayOfInterval({ start, end })` | Every date/day from start through end, inclusive |

An interval is a value describing a range. Its `{ start, end }` object gives the endpoints explicit names. Some functions also accept an optional options argument for choices such as fractional results or locale.

```ts
import { toPlainDate, differenceInDays, eachDayOfInterval, addDays, isBefore } from '@gobrand/tiempo';

const start = toPlainDate('2026-10-10');
const end = toPlainDate('2026-10-12');

const dayCount = differenceInDays(end, start); // 2
const reversedCount = differenceInDays(start, end); // -2
const calendarDates = eachDayOfInterval({ start, end }).map(date => date.toString());
// ['2026-10-10', '2026-10-11', '2026-10-12']
const nextDay = addDays(start, 1).toString(); // '2026-10-11'
const isEarlier = isBefore(start, end); // true
```

There are **two days between** these endpoints and **three dates in** the inclusive interval.

## Choose the value that matches your task

| Value | Use it for | Example |
|-------|------------|---------|
| `PlainDate` | Calendar dates without a clock or timezone | A birthday, deadline date, or date-picker selection |
| `Instant` | One exact point in time | A timestamp stored in a database |
| `ZonedDateTime` | An exact time with timezone and calendar context | An event viewed in America/New_York |
| `PlainTime` | Clock time without a date or timezone | A daily opening time |

Calendar differences and day/week/month/quarter/year intervals accept two PlainDates, or a compatible Instant/ZonedDateTime pair. They reject mixing PlainDate with a timestamp. Convert a timestamp with `toPlainDate(timestamp, timezone)` when your task is about its local date. Parse strings explicitly with the conversion functions.

Date-only inputs produce date-only interval results. Timeline intervals produce ZonedDateTimes; an Instant start uses UTC. Native Temporal and polyfill values may be mixed within a supported domain.

## Period intervals include boundary starts

`eachWeekOfInterval`, `eachMonthOfInterval`, `eachQuarterOfInterval`, and `eachYearOfInterval` return the start of every period touched by the interval. The first result can be before the input's start date. Weeks begin on Monday. Reversed original endpoints return `[]`.

```ts
import { toPlainDate, eachMonthOfInterval } from '@gobrand/tiempo';

const monthStarts = eachMonthOfInterval({
  start: toPlainDate('2026-01-15'),
  end: toPlainDate('2026-03-02'),
}).map(date => date.toString());
// ['2026-01-01', '2026-02-01', '2026-03-01']
```

## Whole and fractional differences

Differences truncate toward zero by default. Pass `{ fractional: true }` for fractional weeks, months or years. PlainDate day differences are always integers because dates have no clock component.

Calendar differences use matching calendars and the second argument as their reference. Months and years have variable lengths, so fractional results can depend on direction. Do not assume swapping any two calendar inputs always gives the exact negative fractional result. Date intervals use the start calendar, interpreting their end in that context.
