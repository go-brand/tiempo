---
title: addBusinessDays
description: Add Monday–Friday days, skipping weekends
---

Adds business days (Monday–Friday), skipping Saturdays and Sundays. Use it for due dates like "reply within 3 business days". Holidays are not considered.

## Signature

```ts
function addBusinessDays(input: Temporal.PlainDate, days: number): Temporal.PlainDate;
function addBusinessDays(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  days: number
): Temporal.ZonedDateTime
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `PlainDate`, `Instant`, or `ZonedDateTime` | The starting value |
| `days` | `number` | Whole business days to add; negative subtracts |

## Returns

A `PlainDate` for a PlainDate input, otherwise a `ZonedDateTime`. Throws a `RangeError` if `days` is not an integer.

## Examples

### Set a due date a few business days out

```ts
import { addBusinessDays } from '@gobrand/tiempo';

const friday = Temporal.PlainDate.from('2026-01-23');

addBusinessDays(friday, 1); // 2026-01-26
addBusinessDays(friday, 5); // 2026-01-30
addBusinessDays(friday, -1); // 2026-01-22
```

### Keep the local time across a DST change

```ts
import { addBusinessDays } from '@gobrand/tiempo';

const received = Temporal.ZonedDateTime.from('2026-03-06T09:00:00-05:00[America/New_York]');

addBusinessDays(received, 1); // 2026-03-09T09:00:00-04:00[America/New_York] (still 09:00 after DST starts)
```

### Skip your own holidays

```ts
import { addBusinessDays } from '@gobrand/tiempo';

const holidays = new Set(['2026-01-26']);

function addWorkingDays(date: Temporal.PlainDate, days: number): Temporal.PlainDate {
  let result = date;
  for (let i = 0; i < days; i++) {
    do result = addBusinessDays(result, 1);
    while (holidays.has(result.toString()));
  }
  return result;
}

addWorkingDays(Temporal.PlainDate.from('2026-01-23'), 1); // 2026-01-27
```

## Good to know

- Starting on a weekend, the first business day counted is the next Monday (or the previous Friday for negative values). Adding 0 returns the same date, even on a weekend.
