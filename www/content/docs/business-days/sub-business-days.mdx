---
title: subBusinessDays
description: Subtract Monday–Friday days, skipping weekends and holidays
---

Subtracts business days (Monday–Friday), skipping Saturdays, Sundays, and any holidays you pass. Same as `addBusinessDays(input, -days, holidays)`.

## Signature

```ts
function subBusinessDays(
  input: Temporal.PlainDate,
  days: number,
  holidays?: readonly Temporal.PlainDate[]
): Temporal.PlainDate;
function subBusinessDays(
  input: Temporal.Instant | Temporal.ZonedDateTime,
  days: number,
  holidays?: readonly Temporal.PlainDate[]
): Temporal.ZonedDateTime
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `PlainDate`, `Instant`, or `ZonedDateTime` | The starting value |
| `days` | `number` | Whole business days to subtract; negative adds |
| `holidays` | `readonly PlainDate[]` | Optional dates that are not business days. Instant and ZonedDateTime inputs match them against their own date (UTC for an Instant) |

## Returns

A `PlainDate` for a PlainDate input, otherwise a `ZonedDateTime`. Throws a `RangeError` if `days` is not an integer.

## Examples

### Find the last day to submit before a deadline

```ts
import { subBusinessDays } from '@gobrand/tiempo';

const launch = Temporal.PlainDate.from('2026-01-26'); // a Monday

subBusinessDays(launch, 1); // 2026-01-23
subBusinessDays(launch, 10); // 2026-01-12
```
