---
title: isPlainTimeEqual
description: Check whether two wall-clock times are the same.
---

Returns `true` when both times are the same, down to the nanosecond. Same answer as [isEqual](/docs/comparison/is-equal), but accepts only PlainTimes.

## Signature

```ts
function isPlainTimeEqual(time1: Temporal.PlainTime, time2: Temporal.PlainTime): boolean;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `time1` | `PlainTime` | The first time |
| `time2` | `PlainTime` | The second time |

## Returns

`true` if both times are equal, otherwise `false`.

## Examples

### Check whether a class starts at the booked time

```ts
import { isPlainTimeEqual } from '@gobrand/tiempo';

const booking = Temporal.PlainTime.from('18:30');

isPlainTimeEqual(Temporal.PlainTime.from('18:30:00'), booking); // true
isPlainTimeEqual(Temporal.PlainTime.from('18:30:00.001'), booking); // false (fractions count)
```
