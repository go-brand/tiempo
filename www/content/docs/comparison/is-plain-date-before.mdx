---
title: isPlainDateBefore
description: Check whether one calendar date comes before another.
---

Returns `true` when the first date comes before the second. Same answer as [isBefore](/docs/comparison/is-before), but accepts only PlainDates.

## Signature

```ts
function isPlainDateBefore(date1: Temporal.PlainDate, date2: Temporal.PlainDate): boolean;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `date1` | `PlainDate` | The date being checked |
| `date2` | `PlainDate` | The date to compare against |

## Returns

`true` if `date1` is before `date2`, otherwise `false`. Equal dates return `false`.

## Examples

### Check that a leave request starts before it ends

```ts
import { isPlainDateBefore } from '@gobrand/tiempo';

const firstDay = Temporal.PlainDate.from('2026-07-27');
const lastDay = Temporal.PlainDate.from('2026-08-07');

isPlainDateBefore(firstDay, lastDay); // true
isPlainDateBefore(firstDay, firstDay); // false (same day)
```
