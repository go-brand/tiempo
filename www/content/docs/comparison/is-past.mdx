---
title: isPast
description: Check whether a timestamp is earlier than the current moment.
---

Returns `true` when the timestamp is before the current instant. It compares exact instants, so it needs no timezone.

## Signature

```ts
function isPast(date: Temporal.Instant | Temporal.ZonedDateTime): boolean;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `date` | `Instant \| ZonedDateTime` | The timestamp to check |

## Returns

`true` if `date` is before the current instant, otherwise `false`.

## Examples

### Check whether a coupon has expired

```ts
import { isPast } from '@gobrand/tiempo';

isPast(Temporal.ZonedDateTime.from('2020-05-31T23:59:59+02:00[Europe/Madrid]')); // true
isPast(Temporal.Instant.from('2100-01-01T00:00:00Z')); // false
```

## Good to know

- To compare against a time other than now, use [isBefore](/docs/comparison/is-before). For a calendar day, use [isYesterday](/docs/comparison/is-yesterday), which takes a timezone.
