---
title: isSameMonth
description: Check whether two timestamps fall in the same calendar month.
---

Returns `true` when both timestamps fall in the same month of the same year. Like [isSameDay](/docs/comparison/is-same-day), each value is read in its own timezone, with Instants in UTC.

## Signature

```ts
function isSameMonth(
  date1: Temporal.Instant | Temporal.ZonedDateTime,
  date2: Temporal.Instant | Temporal.ZonedDateTime
): boolean;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `date1` | `Instant \| ZonedDateTime` | The first timestamp |
| `date2` | `Instant \| ZonedDateTime` | The second timestamp |

## Returns

`true` if both values have the same year and month in their own timezones, otherwise `false`.

## Examples

### Put a payment on the right monthly statement

```ts
import { isSameMonth } from '@gobrand/tiempo';

const payment = Temporal.ZonedDateTime.from('2026-01-31T20:00:00-05:00[America/New_York]');
const statementStart = Temporal.ZonedDateTime.from('2026-01-01T00:00:00-05:00[America/New_York]');

isSameMonth(payment, statementStart); // true (both January in New York)
isSameMonth(payment.toInstant(), statementStart.toInstant()); // false (the payment is February 1 in UTC)
```
