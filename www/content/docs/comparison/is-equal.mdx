---
title: isEqual
description: Check whether two dates, times, or timestamps are the same.
---

Returns `true` when both values are the same date, the same time, or the same instant. Timestamps written in different timezones are equal when they are the same moment.

## Signature

```ts
function isEqual(date1: Temporal.PlainDate, date2: Temporal.PlainDate): boolean;
function isEqual(date1: Temporal.PlainTime, date2: Temporal.PlainTime): boolean;
function isEqual(
  date1: Temporal.Instant | Temporal.ZonedDateTime,
  date2: Temporal.Instant | Temporal.ZonedDateTime
): boolean;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `date1` | `PlainDate`, `PlainTime`, `Instant`, or `ZonedDateTime` | The first value |
| `date2` | Same kind as `date1`; `Instant` and `ZonedDateTime` can be mixed | The second value |

## Returns

`true` if `date1` equals `date2`, otherwise `false`.

## Examples

### Match the same moment stored in different timezones

```ts
import { isEqual } from '@gobrand/tiempo';

const newYork = Temporal.ZonedDateTime.from('2026-01-20T10:00:00-05:00[America/New_York]');
const utc = Temporal.Instant.from('2026-01-20T15:00:00Z');

isEqual(newYork, utc); // true
```

### Compare two dates or two clock times

```ts
import { isEqual } from '@gobrand/tiempo';

isEqual(Temporal.PlainDate.from('2026-01-20'), Temporal.PlainDate.from('2026-01-21')); // false
isEqual(Temporal.PlainTime.from('09:00'), Temporal.PlainTime.from('09:00:00.000')); // true
```

## Good to know

- Comparing a PlainDate, a PlainTime, and a timestamp with each other is a TypeScript error and throws a `TypeError`.
- To compare wall-clock readings instead of instants, use [isSameNanosecond](/docs/comparison/is-same-nanosecond). To also require the same timezone and calendar, use `zoned1.equals(zoned2)`.
