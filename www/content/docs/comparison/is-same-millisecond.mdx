---
title: isSameMillisecond
description: Check whether two timestamps fall in the same millisecond.
---

Returns `true` when both timestamps fall in the same millisecond, ignoring microseconds and nanoseconds. Like [isSameDay](/docs/comparison/is-same-day), each value is read in its own timezone, with Instants in UTC.

## Signature

```ts
function isSameMillisecond(
  date1: Temporal.Instant | Temporal.ZonedDateTime,
  date2: Temporal.Instant | Temporal.ZonedDateTime
): boolean;
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `date1` | `Instant \| ZonedDateTime` | The first timestamp |
| `date2` | `Instant \| ZonedDateTime` | The second timestamp |

## Returns

`true` if both values match from the year down to the millisecond in their own timezones, otherwise `false`.

## Examples

### Match a timestamp after a round trip through epoch milliseconds

```ts
import { isEqual, isSameMillisecond } from '@gobrand/tiempo';

const fromServer = Temporal.Instant.from('2026-06-01T08:00:00.123456789Z');
const fromBrowser = Temporal.Instant.fromEpochMilliseconds(fromServer.epochMilliseconds);

isSameMillisecond(fromServer, fromBrowser); // true
isEqual(fromServer, fromBrowser); // false (the browser copy lost 456789 ns)
```
