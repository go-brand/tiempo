---
title: toDate
description: Turn an Instant or ZonedDateTime into a JavaScript Date.
---

Turns a moment into a JavaScript `Date`, for drivers and libraries that only accept `Date`.

## Signature

```ts
function toDate(
  input: Temporal.Instant | Temporal.ZonedDateTime
): Date
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.Instant \| Temporal.ZonedDateTime` | The moment to convert. |

## Returns

A `Date` for the same moment.

## Examples

### Save a renewal time to a Date column

```ts
import { toDate } from '@gobrand/tiempo';

const renewsAt = Temporal.ZonedDateTime.from('2026-04-01T09:00:00[America/New_York]');

toDate(renewsAt).toISOString(); // "2026-04-01T13:00:00.000Z"
```

### Read it back in the user's timezone

```ts
import { toDate, toZonedTime } from '@gobrand/tiempo';

const stored = toDate(Temporal.Instant.from('2026-04-01T13:00:00Z'));

toZonedTime(stored, 'America/New_York'); // 2026-04-01T09:00:00-04:00[America/New_York]
```

## Good to know

- A `Date` has no timezone and stores whole milliseconds, so the timezone and any digits past milliseconds are dropped.
