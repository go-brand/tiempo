---
title: toPlainDate
description: Get a calendar date from a string, fields, or a timestamp.
---

Returns a calendar date with no time. A timestamp needs a timezone, because the same moment can fall on different dates in different places.

## Signature

```ts
function toPlainDate(input: Temporal.ZonedDateTime): Temporal.PlainDate

function toPlainDate(
  input: string | Date | Temporal.Instant | Temporal.ZonedDateTime,
  timezone: Timezone
): Temporal.PlainDate

function toPlainDate(input: Temporal.PlainDateLike | string): Temporal.PlainDate
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `string \| Date \| Temporal.Instant \| Temporal.ZonedDateTime \| Temporal.PlainDateLike` | A `YYYY-MM-DD` string, `{ year, month, day }`, a `PlainDate`, a `ZonedDateTime`, or a timestamp. |
| `timezone` | `Timezone` | Required for timestamps (ISO strings with a time, `Date`, `Instant`). With a `ZonedDateTime`, moves it to this timezone first. |

## Returns

A `Temporal.PlainDate`.

## Examples

### Read a date picker value

```ts
import { toPlainDate } from '@gobrand/tiempo';

toPlainDate('2026-07-15'); // 2026-07-15
toPlainDate({ year: 2026, month: 7, day: 15 }); // 2026-07-15
```

### Find which day an order belongs to

```ts
import { toPlainDate } from '@gobrand/tiempo';

const placedAt = '2026-01-20T23:30:00Z';

toPlainDate(placedAt, 'Asia/Tokyo'); // 2026-01-21
toPlainDate(placedAt, 'America/New_York'); // 2026-01-20
```

### Get a hotel check-in date

```ts
import { toPlainDate } from '@gobrand/tiempo';

const checkIn = Temporal.ZonedDateTime.from('2026-08-14T15:00:00[Europe/Lisbon]');

toPlainDate(checkIn); // 2026-08-14
```

## Good to know

- Without a timezone, a string must be exactly `YYYY-MM-DD`; with one, it must be a timestamp. Otherwise it throws.
- Fields are clamped, strings are not: `{ year: 2026, month: 2, day: 30 }` gives `2026-02-28`, while `'2026-02-30'` throws a `RangeError`.
