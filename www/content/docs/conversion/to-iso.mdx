---
title: toIso
description: Turn an Instant or ZonedDateTime into an ISO 8601 string.
---

Turns a moment into an ISO 8601 string, in UTC by default.

## Signature

```ts
function toIso(input: Temporal.Instant): string

function toIso(
  input: Temporal.ZonedDateTime,
  options?: { mode?: 'utc' | 'offset' }
): string
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.Instant \| Temporal.ZonedDateTime` | The moment to write out. |
| `options.mode` | `'utc' \| 'offset'` | ZonedDateTime only. `'utc'` (default) writes UTC with `Z`. `'offset'` writes the local time with its offset. |

## Returns

An ISO 8601 string, such as `2026-06-02T16:30:00Z`.

## Examples

### Send a booking time to an API in UTC

```ts
import { toIso } from '@gobrand/tiempo';

const slot = Temporal.ZonedDateTime.from('2026-06-02T09:30:00[America/Los_Angeles]');

toIso(slot); // 2026-06-02T16:30:00Z
toIso(slot, { mode: 'offset' }); // 2026-06-02T09:30:00-07:00
```

### Write out a payment timestamp

```ts
import { toIso } from '@gobrand/tiempo';

toIso(Temporal.Instant.from('2026-03-31T22:15:00.250Z')); // 2026-03-31T22:15:00.25Z
```

## Good to know

- The result never includes the timezone name. Use `zoned.toString()` to keep it: `2026-06-02T09:30:00-07:00[America/Los_Angeles]`.
