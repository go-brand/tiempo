---
title: toIso9075
description: Turn an Instant or ZonedDateTime into a SQL datetime string.
---

Turns a moment into a SQL datetime string such as `2026-05-18 07:45:00`, in UTC by default.

## Signature

```ts
function toIso9075(
  input: Temporal.Instant,
  options?: { representation?: 'complete' | 'date' | 'time' }
): string

function toIso9075(
  input: Temporal.ZonedDateTime,
  options?: {
    mode?: 'utc' | 'local';
    representation?: 'complete' | 'date' | 'time';
  }
): string
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `Temporal.Instant \| Temporal.ZonedDateTime` | The moment to write out. |
| `options.mode` | `'utc' \| 'local'` | ZonedDateTime only. `'utc'` (default) converts to UTC. `'local'` keeps the time in its own timezone. |
| `options.representation` | `'complete' \| 'date' \| 'time'` | Date and time (default), date only, or time only. |

## Returns

A string: `2026-05-18 07:45:00`, `2026-05-18`, or `07:45:00`.

## Examples

### Store a shift start in a DATETIME column

```ts
import { toIso9075 } from '@gobrand/tiempo';

const shiftStart = Temporal.ZonedDateTime.from('2026-05-18T09:45:00[Europe/Berlin]');

toIso9075(shiftStart); // "2026-05-18 07:45:00"
toIso9075(shiftStart, { mode: 'local' }); // "2026-05-18 09:45:00"
```

### Fill separate DATE and TIME columns

```ts
import { toIso9075 } from '@gobrand/tiempo';

const loggedAt = Temporal.Instant.from('2026-05-18T23:30:15.987Z');

toIso9075(loggedAt, { representation: 'date' }); // 2026-05-18
toIso9075(loggedAt, { representation: 'time' }); // 23:30:15
```

## Good to know

- Fractional seconds are cut off, not rounded.
