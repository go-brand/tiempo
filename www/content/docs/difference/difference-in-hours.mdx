---
title: differenceInHours
description: Count the hours elapsed between two datetimes
---

Returns the hours elapsed from `earlierDate` to `laterDate`. It measures real elapsed time, so a shift that crosses a DST change counts the hours actually worked.

## Signature

```ts
function differenceInHours(
  laterDate: Temporal.Instant | Temporal.ZonedDateTime,
  earlierDate: Temporal.Instant | Temporal.ZonedDateTime,
  options?: DifferenceOptions
): number

interface DifferenceOptions {
  fractional?: boolean;
}
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `laterDate` | `Instant \| ZonedDateTime` | The value to subtract from |
| `earlierDate` | `Instant \| ZonedDateTime` | The value to subtract |
| `options.fractional` | `boolean` | Return the exact value instead of truncating toward zero (default `false`) |

## Returns

A signed number of hours, truncated toward zero unless `fractional` is set.

## Examples

### Hours worked on a shift that crosses DST

```ts
import { differenceInHours } from '@gobrand/tiempo';

const clockIn = Temporal.ZonedDateTime.from('2026-10-31T22:00:00-04:00[America/New_York]');
const clockOut = Temporal.ZonedDateTime.from('2026-11-01T06:00:00-05:00[America/New_York]');

differenceInHours(clockOut, clockIn); // 9 (clocks went back an hour at 02:00)
```

### Bill a shift in fractional hours

```ts
import { differenceInHours } from '@gobrand/tiempo';

const start = Temporal.ZonedDateTime.from('2026-05-04T09:00:00+02:00[Europe/Madrid]');
const end = Temporal.ZonedDateTime.from('2026-05-04T17:30:00+02:00[Europe/Madrid]');

differenceInHours(end, start); // 8
differenceInHours(end, start, { fractional: true }); // 8.5
```
