---
title: differenceInMonths
description: Count the calendar months between two dates or datetimes
---

Returns the calendar months from `earlierDate` to `laterDate`. A month is complete when the same day of the month comes round again.

## Signature

```ts
function differenceInMonths(
  laterDate: Temporal.PlainDate,
  earlierDate: Temporal.PlainDate,
  options?: DifferenceOptions
): number

function differenceInMonths(
  laterDate: Temporal.Instant | Temporal.ZonedDateTime,
  earlierDate: Temporal.Instant | Temporal.ZonedDateTime,
  options?: DifferenceOptions
): number

interface DifferenceOptions {
  fractional?: boolean;
}
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `laterDate` | `PlainDate` or `Instant \| ZonedDateTime` | The value to subtract from |
| `earlierDate` | Same kind as `laterDate` | The value to subtract |
| `options.fractional` | `boolean` | Return the exact value instead of truncating toward zero (default `false`) |

## Returns

A signed number of months, truncated toward zero unless `fractional` is set.

## Examples

### Count the billed months of a subscription

```ts
import { differenceInMonths } from '@gobrand/tiempo';

const subscribed = Temporal.PlainDate.from('2026-01-15');
const cancelled = Temporal.PlainDate.from('2026-11-08');

differenceInMonths(cancelled, subscribed); // 9
```

### A subscription that starts at month end

```ts
import { differenceInMonths } from '@gobrand/tiempo';

const subscribed = Temporal.PlainDate.from('2026-01-31');

differenceInMonths(Temporal.PlainDate.from('2026-02-27'), subscribed); // 0
differenceInMonths(Temporal.PlainDate.from('2026-02-28'), subscribed); // 1 (February has no 31st)
```

### Get partial months

```ts
import { differenceInMonths } from '@gobrand/tiempo';

const start = Temporal.Instant.from('2026-01-01T00:00:00Z');
const end = Temporal.Instant.from('2026-02-15T00:00:00Z');

differenceInMonths(end, start, { fractional: true }); // 1.5 (14 of February's 28 days)
```

## Good to know

- Fractions are measured from `earlierDate`, so swapping the arguments need not give exactly the opposite fraction.
- To count month changes instead, so January 31 to February 1 is 1, use [differenceInCalendarMonths](/docs/difference/difference-in-calendar-months).
- Mixing a PlainDate with an Instant or ZonedDateTime is a TypeScript error and throws a `TypeError`.
