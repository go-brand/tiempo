---
title: differenceInMilliseconds
description: Count the milliseconds elapsed between two datetimes
---

Returns the whole milliseconds elapsed from `earlierDate` to `laterDate`, truncated toward zero.

## Signature

```ts
function differenceInMilliseconds(
  laterDate: Temporal.Instant | Temporal.ZonedDateTime,
  earlierDate: Temporal.Instant | Temporal.ZonedDateTime
): number
```

## Examples

### Measure how long a request took

```ts
import { differenceInMilliseconds } from '@gobrand/tiempo';

const sent = Temporal.Instant.from('2026-05-04T09:30:00.000Z');
const received = Temporal.Instant.from('2026-05-04T09:30:01.250Z');

differenceInMilliseconds(received, sent); // 1250
```
