---
title: differenceInMinutes
description: Count the minutes elapsed between two datetimes
---

Returns the minutes elapsed from `earlierDate` to `laterDate`. The two values can be in different timezones.

## Signature

```ts
function differenceInMinutes(
  laterDate: Temporal.Instant | Temporal.ZonedDateTime,
  earlierDate: Temporal.Instant | Temporal.ZonedDateTime,
  options?: DifferenceOptions
): number

interface DifferenceOptions {
  fractional?: boolean;
}
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `laterDate` | `Instant \| ZonedDateTime` | The value to subtract from |
| `earlierDate` | `Instant \| ZonedDateTime` | The value to subtract |
| `options.fractional` | `boolean` | Return the exact value instead of truncating toward zero (default `false`) |

## Returns

A signed number of minutes, truncated toward zero unless `fractional` is set.

## Examples

### Flight time from Madrid to New York

```ts
import { differenceInMinutes } from '@gobrand/tiempo';

const departure = Temporal.ZonedDateTime.from('2026-06-12T11:45:00+02:00[Europe/Madrid]');
const arrival = Temporal.ZonedDateTime.from('2026-06-12T14:20:00-04:00[America/New_York]');

differenceInMinutes(arrival, departure); // 515 (8 h 35 min)
```

### Length of a support call

```ts
import { differenceInMinutes } from '@gobrand/tiempo';

const answered = Temporal.Instant.from('2026-05-04T09:30:00Z');
const ended = Temporal.Instant.from('2026-05-04T09:42:30Z');

differenceInMinutes(ended, answered); // 12
differenceInMinutes(ended, answered, { fractional: true }); // 12.5
```
