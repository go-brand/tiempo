---
title: differenceInYears
description: Count the full years between two dates or datetimes
---

Returns the full calendar years from `earlierDate` to `laterDate`. For someone's current age, pass [today](/docs/current-time/today): `differenceInYears(today('Europe/Madrid'), birthday)`.

## Signature

```ts
function differenceInYears(
  laterDate: Temporal.PlainDate,
  earlierDate: Temporal.PlainDate,
  options?: DifferenceOptions
): number

function differenceInYears(
  laterDate: Temporal.Instant | Temporal.ZonedDateTime,
  earlierDate: Temporal.Instant | Temporal.ZonedDateTime,
  options?: DifferenceOptions
): number

interface DifferenceOptions {
  fractional?: boolean;
}
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `laterDate` | `PlainDate` or `Instant \| ZonedDateTime` | The value to subtract from |
| `earlierDate` | Same kind as `laterDate` | The value to subtract |
| `options.fractional` | `boolean` | Return the exact value instead of truncating toward zero (default `false`) |

## Returns

A signed number of years, truncated toward zero unless `fractional` is set.

## Examples

### Calculate someone's age

```ts
import { differenceInYears } from '@gobrand/tiempo';

const birthday = Temporal.PlainDate.from('1990-11-09');

differenceInYears(Temporal.PlainDate.from('2026-11-08'), birthday); // 35
differenceInYears(Temporal.PlainDate.from('2026-11-09'), birthday); // 36
```

### Someone born on 29 February

```ts
import { differenceInYears } from '@gobrand/tiempo';

const birthday = Temporal.PlainDate.from('2008-02-29');

differenceInYears(Temporal.PlainDate.from('2026-02-28'), birthday); // 18 (28 February completes the year)
```

## Good to know

- To count year changes instead, so December 31 to January 1 is 1, use [differenceInCalendarYears](/docs/difference/difference-in-calendar-years).
- Mixing a PlainDate with an Instant or ZonedDateTime is a TypeScript error and throws a `TypeError`.
