---
title: eachQuarterOfInterval
description: List the first day of each quarter a range touches
---

Returns the first day of every quarter (1 January, 1 April, 1 July, 1 October) from the quarter containing `start` to the quarter containing `end`.

## Signature

```ts
function eachQuarterOfInterval(interval: {
  start: Temporal.Instant | Temporal.ZonedDateTime;
  end: Temporal.Instant | Temporal.ZonedDateTime;
}): Temporal.ZonedDateTime[]

function eachQuarterOfInterval(interval: {
  start: Temporal.PlainDate;
  end: Temporal.PlainDate;
}): Temporal.PlainDate[]
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `interval.start` | `PlainDate` or `Instant \| ZonedDateTime` | Start of the range |
| `interval.end` | Same kind as `start` | End of the range, included |

## Returns

PlainDate endpoints give a `PlainDate[]`. Instant or ZonedDateTime endpoints give a `ZonedDateTime[]` at the start of each quarter, in the timezone of `start` (UTC for an Instant). A reversed range gives `[]`.

## Examples

### Columns for a fiscal report that crosses the new year

```ts
import { eachQuarterOfInterval } from '@gobrand/tiempo';

const quarters = eachQuarterOfInterval({
  start: Temporal.PlainDate.from('2025-11-10'),
  end: Temporal.PlainDate.from('2026-08-01'),
});

quarters.map(String); // ['2025-10-01', '2026-01-01', '2026-04-01', '2026-07-01']
```

## Good to know

- Mixing a PlainDate with an Instant or ZonedDateTime is a TypeScript error and throws a `TypeError`.
