---
title: eachYearOfInterval
description: List 1 January of each year a range touches
---

Returns 1 January of every year from the year containing `start` to the year containing `end`.

## Signature

```ts
function eachYearOfInterval(interval: {
  start: Temporal.PlainDate;
  end: Temporal.PlainDate;
}): Temporal.PlainDate[]

function eachYearOfInterval(interval: {
  start: Temporal.Instant | Temporal.ZonedDateTime;
  end: Temporal.Instant | Temporal.ZonedDateTime;
}): Temporal.ZonedDateTime[]
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `interval.start` | `PlainDate` or `Instant \| ZonedDateTime` | Start of the range |
| `interval.end` | Same kind as `start` | End of the range, included |

## Returns

PlainDate endpoints give a `PlainDate[]`. Instant or ZonedDateTime endpoints give a `ZonedDateTime[]` at the start of each 1 January, in the timezone of `start` (UTC for an Instant). A reversed range gives `[]`.

## Examples

### Year columns for a revenue chart

```ts
import { eachYearOfInterval } from '@gobrand/tiempo';

const years = eachYearOfInterval({
  start: Temporal.PlainDate.from('2024-06-01'),
  end: Temporal.PlainDate.from('2026-03-01'),
});

years.map((year) => year.year); // [2024, 2025, 2026]
```

### A two-hour range can span two years

```ts
import { eachYearOfInterval } from '@gobrand/tiempo';

const years = eachYearOfInterval({
  start: Temporal.Instant.from('2025-12-31T23:00:00Z'),
  end: Temporal.Instant.from('2026-01-01T01:00:00Z'),
});

years.map(String); // ['2025-01-01T00:00:00+00:00[UTC]', '2026-01-01T00:00:00+00:00[UTC]']
```

## Good to know

- Mixing a PlainDate with an Instant or ZonedDateTime is a TypeScript error and throws a `TypeError`.
