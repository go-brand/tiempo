# Date and time guides

Each guide answers one question about dates and times in JavaScript, with examples that run in tiempo's test suite.

- [Replace JavaScript Date with Temporal](https://tiempo.gobrand.app/docs/guides/replace-date-with-temporal): What is wrong with Date, which Temporal type to use, and what to replace
- [Choose a JavaScript date library](https://tiempo.gobrand.app/docs/guides/choose-a-date-library): date-fns, Day.js, Luxon, Moment.js, and Temporal compared
- [Convert UTC to a user's timezone](https://tiempo.gobrand.app/docs/guides/convert-utc-to-timezone): Show UTC timestamps in any IANA timezone and send UTC back
- [Add days across daylight saving time](https://tiempo.gobrand.app/docs/guides/dst-safe-date-math): Why 24 hours is not a day, and date math that survives DST
- [Start and end of day in a timezone](https://tiempo.gobrand.app/docs/guides/start-and-end-of-day): Midnight in the user's timezone and one-day database queries
- [Store dates in a database](https://tiempo.gobrand.app/docs/guides/store-dates-in-a-database): Column types for timestamps, birthdays, and future events
- [Count business days with holidays](https://tiempo.gobrand.app/docs/guides/business-days-with-holidays): Due dates and working-day counts that skip weekends and holidays
